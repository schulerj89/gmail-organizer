# Changelog

## [Unreleased]

## [0.1.0] - 2026-07-26

### Added

- Local-first Go API and React cleanup workbench.
- Gmail OAuth and metadata-only mailbox scanning.
- Heuristic and optional OpenAI Responses API classification.
- Category, sender, unsubscribe, suggested-cleanup, and AI review queues.
- Manual corrections and reusable sender rules.
- SQLite-backed review state, coverage metrics, and action audit history.
- Preview-and-confirm flows for Trash and one-click unsubscribe actions.
- Demo data, guided onboarding, dark mode, and responsive cleanup workflows.
- Paged scans, bounded caches, batched Gmail actions, and configurable AI limits.
- Public contribution, security, issue, pull request, CI, and dependency-update configuration.
